# Market data normalizer

`backend.src.market_data_normalizer.indexes` provides the explicit `gather_index_data(data_dir=None)` function. It reads the acquired IBOVESPA, IFIX, Selic and S&P 500 source files with pandas and writes the derived `normalized/gathered_data.csv` beneath the chosen data root. The default root is the repository's `data` directory and does not depend on the caller's working directory.

The service owns only local CSV layout conversion. Its B3 reader expands the annual day-by-month matrix; its daily-series reader accepts the canonical Selic and Yahoo getter schemas. The orchestration joins by source date and retains original values and units. It does not acquire data, touch backups, infer missing values, define portfolio behavior, or depend on FastAPI. Imports have no file or network side effects.

The table includes the union of dates with at least one observation and keeps missing asset cells blank. Invalid, empty, malformed or duplicate source observations stop the operation. Pandas writes a temporary file in the destination directory, and `os.replace` publishes it only after a successful write. Existing source files are read-only; the derived output is reproducible from those files.

`backend.src.market_data_normalizer.daily_returns` provides the explicit `generate_daily_returns_reais(data_dir=None)` service. It reads `normalized/gathered_data.csv` and direct CSV files under `dolar/source/`, interpreting the prepared currency schema `Data,price` with `DD.MM.YYYY` dates and decimal-comma prices. It writes `normalized/daily_returns_reais.csv` under the selected data root, independent of the caller's working directory. It does not acquire data, modify source files, define backtest calendar alignment or depend on FastAPI. Imports have no file or network side effects.

The daily-return output contains gathered dates after the first row and uses decimal returns. IBOVESPA and IFIX compare against their most recent prior nonmissing levels, and missing observations yield zero without resetting those levels. Selic's daily percentage is divided by 100; a missing value yields zero. S&P 500 combines its price change with USD/BRL change by multiplying their growth factors. A missing same-day currency price uses the latest earlier currency observation. The currency baseline for each S&P return is the price associated with the prior available S&P observation. Missing S&P observations yield zero and preserve both baselines, so currency changes during gaps are included when S&P resumes. If an index or currency baseline is not available, that return is zero until it can be calculated. Invalid schemas, dates, duplicates, non-finite values and nonpositive index or currency levels stop generation before publication. Output is staged in the destination directory and atomically replaced after a complete write.
