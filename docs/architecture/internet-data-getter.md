# Internet data getter

`backend.src.internet_data_getter` owns explicit source acquisition, storage safety and provenance. Its registry selects asset-specific getters for both Python calls and the command-line entry point. Importing the package or starting the API does not make source requests.

The IFIX adapter fetches B3 annual source CSV files. The Selic adapter in `backend/src/internet_data_getter/selic/` drives the BCB SGS 11 chart with Selenium and headless Chrome configured for English labels, waits for the chart iframe form, verifies the displayed values of the masked date fields before refresh, and confirms successful refresh and pagination POST responses from Chrome performance events before accepting page contents. It validates the exact series metadata and table header, rejects date-like malformed rows, and requires both the reported count and pagination end before accepting observations. It creates a UTF-8 two-column CSV transcription. Its service holds the dataset's exclusive lock while it fetches and commits a complete result. Its store owns the active file, manifest, write-ahead record, verified backups, atomic replacement and offline restore. Before unchanged success, recovery or restore, it validates required provenance and compares the record's hash, count and date coverage with the paired CSV. Manifest backup references stay flat; each paired historical manifest remains the source of that version's provenance. Recovery only completes or rolls back when the active CSV and manifest match recorded states, preserving unknown files and the pending record. Offline restore preserves the original source retrieval time and records `restored_at` separately. Selic backups live under `data/backups/selic/` and are not active inputs.

The Selic CSV preserves BCB's displayed daily percentage precision. It does not represent an accumulated investment value or define a portfolio return. Calculation and cross-asset date alignment remain domain decisions outside this acquisition module.
