# Selic Selenium refactor — specification s001

Status: proposed 2026-11-03; paired with plan p001 and awaiting explicit human approval. No implementation has been authorized under this revision.

## Goal and scope

Replace Playwright with Selenium for the existing explicit BCB SGS 11 Selic chart and values-table scrape. Retain the existing daily-rate data conventions, source, observable acquisition behavior and data-safety guarantees. Preserve other existing work unrelated to extraction, including the service, registry, CLI, IFIX and IBOVESPA getters, CSV schema, manifest, backups, recovery and offline restore. Changes to these areas are limited to demonstrated integration needs and documentation; do not redesign them. The earlier Selic acquisition task and its evidence remain intact; it is awaiting final approval separately. This is a new user-requested refactor, not a repair or a reset of that task's rounds.

## Acceptance criteria

- **AC-001 Selenium source:** An explicit Selic acquisition uses Selenium WebDriver to operate the existing BCB SGS 11 chart and values table in a headless Chrome browser. Playwright is no longer needed for Selic extraction. Imports, help and application startup initiate no browser or network access. Browser and driver setup and missing dependency failures are explained clearly.
- **AC-002 Correct complete extraction:** Preserve the existing source interaction: identify series 11 and `% p.d.`, read the source latest date, set 01/01/2011 through that date, refresh the Linear chart, open its values and traverse all pages. Confirm the requested refresh and completed page transitions, and validate metadata, period, unit, exact column identity, published count, strict ordering, unique dates, first observation in 2011 and latest observation equal to the source latest date. Preserve displayed decimal precision and reject malformed, repeated, missing, truncated, inconsistent or inaccessible pages. Bounded waits and orderly browser shutdown apply on success and failure. Failures report an incomplete run and do not publish partial data.
- **AC-003 Preservation:** Keep the existing public Python and command-line selection, report semantics, deterministic `date,rate_percent_per_day` CSV and source provenance behavior. Unchanged, updated, failed, backup, lock, transaction recovery and offline restore behavior remains intact. Keep other asset getters and existing project data intact.
- **AC-004 Dependencies and guidance:** Declare a compatible Selenium dependency in `backend/requirements.txt`, remove Playwright and its now-unused dependencies only if nothing else needs them, and document the required Chrome/driver setup, including Selenium Manager's possible network requirement during an explicit run. Update current acquisition and architecture documentation to match actual behavior; preserve supported Python versions unless a concrete compatibility issue is raised for a decision.
- **AC-005 Offline verification:** Exercise the Selenium source interaction and error boundaries with controlled non-market fixtures, and run relevant existing getter regressions, including storage and registry behavior. Tests must not contact BCB and must retain meaningful existing checks. Capture actual results and any inability to execute them.
- **AC-006 Live evidence:** Run the Selenium scraper against live BCB using a temporary data directory, and independently compare source-reported count, range and representative first, middle and last values with the generated output. Record browser/driver environment, time, results and limitations. If source access or browser setup is unavailable, mark this criterion blocked; never report a mock-only pass as live evidence. Do not modify active project data during this verification.

## Exclusions and decisions

No financial calculations, revised source or data conventions, synthetic market data, scheduler, API or frontend work, unrelated refactors, or acquisition into the active project data directory. Use the source's existing chart and table, rather than substituting an API. Original user request: refactor the Selic data getter using Selenium while keeping changes unrelated to extraction. No human approval of s001/p001 has yet been recorded.
