## Observed failure and diagnosis

CHART-QA-01 blocks AC-001 through AC-004. Chrome loaded the document at the root URL but rendered an empty page with zero chart canvases. React reported an invalid element type of object in `ExampleChart`, and reload reproduced it. The [independent QA record](verification.md#independent-qa--2026-11-04-americasao_paulo) identifies the affected criteria and which checks could not run. The [correction handoff snapshot](evidence/correction-handoff.json) matches the failed QA snapshot.

The pinned `react-apexcharts@1.7.0` entry assigns the component to CommonJS `exports.default = Charts`. Vite 8.3.5’s generated optimized module exports `require_react_apexcharts_min()` as its ESM default. That value is the exports object. On the failed source, a read-only Vite `createServer` probe in middleware mode and `transformRequest("/src/pages/ExampleChart/index.tsx")` produced the assignment `const ReactApexChart = __vite__cjsImport0_reactApexcharts`. The transformed JSX passes that binding as the element type. The Vitest page test mocks the wrapper with a callable default, which is why the existing passing tests did not exercise this interop path. The production bundle’s import shape and render still need browser verification.

## Design

Resolve the wrapper’s import shape at the page boundary in `frontend/src/pages/ExampleChart/`. Accept the component directly when the import is a function. For the known CommonJS exports object, select its callable `default`. Type this boundary for the actual wrapper props and keep any type assertion local to the runtime check. Surface unexpected shapes with an explicit diagnostic. Pass the resolved component the existing chart options and series. Keep the exact MIT pins for `apexcharts@4.7.0` and `react-apexcharts@1.7.0`.

Vite already reports that the optimized dependency needs interop, and the client transform still yields the object. A local adapter makes both observed and expected module shapes explicit. Using the ApexCharts core directly would introduce manual chart lifecycle management and expand the repair. The existing mock points, UTC/date and percent behavior, page organization, accessible table and approved AC-001 through AC-006 remain the requirements for this correction.
