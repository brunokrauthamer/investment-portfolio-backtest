## Risks and design choices

Floating-point calculations avoid intermediate rounding but comparisons in tests use numerical tolerance. Calendar anniversaries are calculated from the anchor, avoiding drift after clamped month ends. The real CSV is read per request to preserve current file contents; malformed data cannot be confused with an empty valid range. A fully lost portfolio has no definable future weights and produces a clear error. The older task's unresolved lone-surrogate error must be checked as part of this request's failure coverage; any actual fix uses a failing regression test first and does not alter that task's state.
